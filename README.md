# Fatima Irfan — Clinical Nutritionist & Global Telehealth Dietitian Portfolio

A modern, clinical-editorial portfolio website built for **Fatima Irfan** (*M.Sc. Nutrition · Doctor of Diet and Nutritional Sciences*), showcasing evidence-based Medical Nutrition Therapy, culturally fluent care plans, interactive nutrition screening calculators, and global telehealth services.

## Key Features
- **Condition-Based Clinical Specialties**: Diabetes & Metabolic Care, Cardiovascular & Lipid Health, Gastrointestinal & Food Allergies, Pediatric & Family Nutrition, Weight Architecture & Sports Fueling, and Culinary & Hospitality Menu Consulting.
- **Signature Wellness Packages**: Structured 1-on-1 MNT consultations, 8-week global telehealth concierge, family & pediatric plans, and hospitality menu advisory.
- **Worldwide Areas of Service**: Interactive regional selector covering Malaysia & Southeast Asia, Middle East & GCC, South Asia, UK & Europe, North America, and Australia & New Zealand across 4 languages (*English, Urdu, Punjabi, Saraiki*).
- **Interactive Clinical Calculators**: Real-time BMR/TDEE/Macro & Hydration estimator alongside WHO Asia-Pacific and Global BMI screening.
- **Consultation Concierge**: Instant WhatsApp, Email, and copyable clinical brief dispatch.

## Tech Stack
- **React 19** + **Vite 6**
- **Tailwind CSS v4**
- **Lucide React** icons

## Getting Started Locally
```bash
npm install
npm run dev
```

## Production Build
